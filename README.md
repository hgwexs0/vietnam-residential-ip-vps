## 原生IP、住宅IP、双ISP，三个词说的不是一回事

原生 IP 说的是 IP 的注册地和归属运营商就在当地。丽萨这条线的上游是越南西贡邮电（SPT），胡志明市本地的宽带运营商，IP 段由它分配，并非从别的机房转租过来。住宅 IP 说的是这个 IP 在数据库里的使用类型被标成了家庭宽带用户。两件事各说各的：一个原生 IP 完全可能被标成 Hosting 类型，一个挂着住宅标记的 IP 也可能是从数据中心段“洗”出来的伪住宅。

“双 ISP”指在 ping0、scamalytics、IPinfo 这类数据库里，这个 IP 同时被读成住宅用户和 ISP 类型，看起来就像一个越南家庭拉了一条宽带在上网。

实际检测的口径并不完全统一。多个测评显示，ping0 读到的是住宅家宽属性，IPinfo 的 Company 字段为 ISP 类型；scamalytics 欺诈值不同测评给出过 0 和 6% 左右两个结果，都落在 0～6% 的低位，差异来自不同时间和不同工具。也有测评指出 IPinfo 的 ASN 字段显示为非 ISP，解释是 ISP 名称存在空格差异，实际仍属同一运营商体系。数据库之间本来就有出入，看综合判断比盯单一字段更靠得住。

这件事为什么影响账号。TikTok、Shopee 这类平台的风控会读 ASN 类型、ISP 归属和风控分数，机房 IP 会被直接标成“非真实本地用户”，结果就是限流或者封号。几十块一个月的“越南 VPS”跑不动号，多半就是这里出的问题：IP 归属写着某数据中心，ASN 是 Hosting。丽萨这条线每台机器独立 IP，不是几十个人共用一段。
